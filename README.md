# Digital Solution Portfolio Website

## GitHub Pages
1. Upload the contents of this folder to your repository.
2. Keep `CNAME` with your custom domain.
3. Enable GitHub Pages from the repository settings.

## Main editable files
- `index.html` — homepage content, service names, contact info and links.
- `assets/style.css` — colours, spacing, typography and responsive layout.
- `assets/script.js` — mobile menu and scroll animations.
- `assets/images/` — placeholder client/creative/project visuals.
- `clients/` — 20 demo client case-study pages.
- `robots.txt` — crawler configuration.
- `sitemap.xml` — search-engine sitemap.

## Important
- Replace every Demo School logo/name and case-study content with real client information before publishing.
- Replace `#` social/project placeholders with real URLs.
- `info@digitalsolution.biz` is used as the proposed business email placeholder.
- The site is static and GitHub Pages compatible.
